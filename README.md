# 🗺️ Навуковыя часопісы Беларусі і рэгіёна — Інтэрактыўная карта і рэестр

Інтэрактыўная вэб-карта і сістэматызаваны каталог акадэмічных перыядычных выданняў **Беларусі і сумежных краін** (Польшча, Літва, Латвія, Чэхія, Германія, Вялікабрытанія), дзе сёння паспяхова публікуюцца беларускія даследчыкі.

Праект створаны для дапамогі навукоўцам, выкладчыкам, аспірантам, незалежным даследчыкам і навукоўцам у эміграцыі ў выбары профільнага рэцэнзаванага выдання.

---

## 🎯 Магчымасці каталога

- **🗺️ Інтэрактыўная карта рэдакцый**: дакладныя каардынаты навуковых устаноў і выдавецтваў (OpenStreetMap + Leaflet).
- **🔍 Імгненны паўнатэкставы пошук**: па назве, выдаўцы, горадзе, навуковых тэматыках, ключавых словах ці ISSN.
- **🏷️ Фільтрацыя па крытэрыях**:
  - **Краіны**: Беларусь, Польшча, Літва, Латвія, Чэхія, Германія, Вялікабрытанія.
  - **Галіны навукі**: гуманітарныя і гісторыя, мовазнаўства і філалогія, фізіка-матэматычныя, тэхнічныя навукі і IT, хімія і матэрыялазнаўства, медыцына, грамадскія навукі і эканоміка.
  - **Індэксацыя і статус**: Пералік ВАК Беларусі, Scopus, Web of Science, DOAJ (Адкрыты доступ), ERIH PLUS, РИНЦ.
  - **Фінансавыя ўмовы**: фільтр па 100% бясплатнай публікацыі (Diamond Open Access / No APC).
- **📋 Падрабязныя карткі выданняў**:
  - Афіцыйныя назвы, ISSN, рэдакцыйныя адрасы і кантакты.
  - Спецыялізацыі і актуальныя навуковыя тэмы (напрыклад: гісторыя ВКЛ, беларуская лінгвістыка, лазерная спектраскапія, цеплафізіка, нанатэхналогіі, трансфармацыі грамадства).
  - Умовы падачы рукапісаў, правілы рэцэнзавання (double-blind), патрабаванні да мовы і арыгінальнасці.
  - Прамыя спасылкі на афіцыйныя сайты і парталы падачы артыкулаў.
  - Акадэмічныя рэкамендацыі для беларускіх навукоўцаў.
- **💾 Экспарт даных**: спампоўка базы ў фаррматах **JSON** і **CSV**.

## 🚀 Як запусціць і разгарнуць на GitHub Pages за 1 хвіліну

Праект пабудаваны **без неабходнасці зборкі (Zero-Build)** на чыстым HTML5, JavaScript і сучасных CDN (Tailwind CSS, Leaflet.js).

### Спосаб 1: Праз інтэрфейс GitHub
1. Стварыце новы рэпазіторый на [GitHub](https://github.com/new) (напрыклад, `belarus-science-journals`).
2. Запампуйце змесціва гэтай тэчкі ў рэпазіторый:
   ```bash
   git init
   git add .
   git commit -m "Першы рэліз інтэрактыўнай карты навуковых часопісаў"
   git branch -M main
   git remote add origin https://github.com/ВАША_ІМЯ/belarus-science-journals.git
   git push -u origin main
   ```
3. Перайдзіце ў налады рэпазіторыя на GitHub: **Settings** → **Pages**.
4. У раздзеле **Build and deployment** абярыце **Deploy from a branch** і пазначце галіну `main` (корань `/root`).
5. Праз 30-60 секунд ваша інтэрактыўная карта будзе даступная па адрасе:
   `https://ВАША_ІМЯ.github.io/belarus-science-journals/`

*Таксама ў рэпазіторый уключаны гатовы аўтаматычны працэс GitHub Actions (`.github/workflows/deploy.yml`).*

### Спосаб 2: Лакальны прагляд на кампутары
Проста двойчы клікніце па файле `index.html` у правадніку файлаў альбо запусціце любы лакальны сервер:
```bash
# Праз Python (калі ўсталяваны):
python -m http.server 8000
```
І адкрыйце `http://localhost:8000`.

## 🤝 Як прапанаваць новы часопіс

Мы вітаем унясенне новых навуковых часопісаў! Каб дадаць выданне:
1. Адкрыйце файл `data/journals.js`.
2. Скапіруйце структуру існага аб'екта:
   ```javascript
   {
     id: "ідэнтыфікатар",
     name: "Назва па-беларуску",
     originalName: "Арыгінальная назва",
     issn: "ISSN",
     country: "Краіна",
     countryCode: "BY | PL | LT ...",
     city: "Горад",
     publisher: "Установа / Выдавецтва",
     coordinates: [шырата, даўгата],
     address: "Паштовы адрас рэдакцыі",
     website: "URL",
     submissionUrl: "URL падачы",
     disciplines: ["Галіна 1", "Галіна 2"],
     primaryTopics: ["Тэма 1", "Тэма 2"],
     indexing: ["ВАК Беларусі", "Scopus", ...],
     quartile: "Q2 / ВАК катэгорыя",
     accessType: "Open Access / Падпісны",
     apc: "Бясплатна / сума",
     languages: ["беларуская", "англійская"],
     frequency: "перыядычнасць",
     guidelines: "Патрабаванні да афармлення",
     notes: "Парады даследчыкам"
   }
   ```
3. Стварыце **Pull Request** альбо апішыце прапанову ў **Issues**.
